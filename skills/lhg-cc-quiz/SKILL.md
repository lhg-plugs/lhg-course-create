# lhg-cc-quiz：配套习题（难度梯度）

> 目标：让习题成为"学习闭环"——学员做完题，才知道自己真学会了。
> 核心纪律：**每章至少 3 道题，覆盖记忆→理解→应用三档，每题带答案和解析。**

## 1. 何时使用

- 讲义写完 → 按本节给每章配习题
- 学员"听懂了但不会用" → 查应用档题目是不是缺了
- 完课率低 → 习题是最低成本的完课抓手，先补习题再改课

## 2. 难度梯度三档

| 档 | 测什么 | 题干关键词 | 示例 |
|---|---|---|---|
| 记忆 | 记住了吗 | 是什么/哪三步/定义 | "选题三步法是哪三步？" |
| 理解 | 真懂了吗 | 为什么/区别/如果…会怎样 | "为什么说'先完成再完美'？" |
| 应用 | 会用吗 | 给你 X，请用 Y 方法做 | "给你 3 个备选选题，用三步法选 1 个" |

三档缺一不可：缺记忆档，基础不牢；缺理解档，知其然不知其所以然；缺应用档，学完不会用——而"会用"才是学员付费的真正目的。

**配比建议**：记忆:理解:应用 = 3:4:3。应用题贵（难出、难改），但最值钱。

## 3. 出题规范

- **每章 ≥3 道**：少了测不出掌握度，多了学员烦（超过 8 道就拆）
- **题干具体**：❌"谈谈你对选题的理解" → ✅"给你 3 个备选选题，用三步法选 1 个并说明理由"
- **一题一测**：一道题只测一个知识点，测两个就拆成两道
- **标注题型**：[单选]/[多选]/[简答]/[实操]，学员有预期
- **标注难度**：[记忆]/[理解]/[应用]，方便学员查漏补缺

## 4. 答案解析写作规范

答案不是"标准答案"，是"第二次讲解"：

- **记忆档**：给准确答案（一句话）
- **理解档**：给答案 + 一句话原理（"因为…"）
- **应用档**：给"言之成理即可" + 评分要点（"重点看是否用了三步法"）

示例：

```
3. [简答][应用] 给你 3 个备选选题，用三步法选出 1 个并说明理由。
答案：略（言之成理即可）。
解析：重点看三点——①是否找了痛点 ②是否定了人群 ③是否验证了需求。
三点全有即满分，不看选的是哪个。
```

铁律：**没答案的习题不许交付**（见 course_audit.py QUIZ-ANS-001 blocker）。

## 5. 习题与大纲一致性

- 每道题必须能对应到大纲某一章的某个知识点，对应不上 → 删（超纲了）
- 大纲每章必须有习题覆盖，零覆盖 → warning（见 CONS-QUIZ-001）
- 应用题优先覆盖"行动项"：大纲让学员"今晚定 3 个选题"，习题就考"交出你的 3 个选题"

## 6. 习题格式模板

```markdown
# 第N章习题

1. [单选][记忆] 题干？
   A. …  B. …  C. …  D. …
   答案：B。解析：一句话原理。

2. [简答][理解] 题干？
   答案：…。解析：…。

3. [实操][应用] 题干？
   答案：略（言之成理即可）。解析：评分要点 ①②③。
```

## 7. 反模式

- ❌ 习题全是记忆档——学员背完就忘，等于没测
- ❌ 题干是"谈谈你的看法"——开放到无法评分，等于没出
- ❌ 有题没答案——学员做完不知道对错，挫败感拉满
- ❌ 习题与大纲脱节——考了没讲的，学员骂娘
- ❌ 一章 10 道题——题海是学校的事，知识付费要"少而精"

## 8. 常见问题 FAQ

**Q：应用题学员不交怎么办？**
A：应用题不强制交，但"交了的有反馈"（点评/加餐）。反馈是应用题的燃料，没反馈就没人交。

**Q：选择题要不要设干扰项？**
A：要，但干扰项要是" plausible 的错"（学员常犯的错），不要是"一眼假的错"。好干扰项本身就是教学。

**Q：答案写多细？**
A：记忆档一句话，理解档三句话，应用档给评分要点。答案太长没人看，太短没人懂。

**Q：可以出开放题吗？**
A：可以，但必须给评分要点。没有评分要点的开放题 = 没法判 = 白出。

**Q：习题放哪里？**
A：每章讲义末尾放本章习题，不要全堆到期末。学完立刻练，趁热打铁。

## 9. 自检与反馈

每次执行完本 skill，做一次轻量自检：

1. 每章 ≥3 道吗？→ 少了补
2. 三档全覆盖吗？→ 缺档补（尤其应用档）
3. 每题有答案解析吗？→ 没有不许交付
4. 题目都能对应到大纲吗？→ 对应不上的删

标准冒烟用例：给定一章讲义，输出 3 道题（三档各 1 道，带答案解析），跑 `course_audit.py` 检查 QUIZ-GRAD-001/QUIZ-ANS-001 是否通过。

反馈渠道：以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-course-create/issues，正文写清"输入 → 错误输出 → 期望输出"。

## 10. 完整一章习题示例（可直接用）

```markdown
# 第1章习题：选题

1. [单选][记忆] 选题三步法是哪三步？
   A. 找热点、蹭流量、追爆款
   B. 找痛点、定人群、验需求
   C. 拍vlog、剪日常、发生活
   答案：B。解析：三步缺一不可，顺序不能反。

2. [简答][理解] 为什么"验需求"这一步不能省？
   答案：没验证的选题可能是自嗨，有人搜、有人问才有流量。
   解析：自嗨式选题是新手最大坑。

3. [实操][应用] 写出你的 3 个备选选题，
   并用三步法说明你最终选哪一个。
   答案：略（言之成理即可）。
   解析：评分看三点——①痛点是否具体 ②人群是否明确
   ③是否做了搜索验证。三点全有即满分。
```

注意第 3 题：答案开放，但评分要点闭合。
开放的是"选哪个"，闭合的是"怎么选"——
这就是应用题的正确姿势。
