# lhg-cc-lecture：逐节讲义（口语化）

> 目标：写出"念出来像聊天"的讲义——学员感觉你在对他一个人说话。
> 核心纪律：**讲义写完必须读出声；舌头打结的地方，重写。**

## 1. 何时使用

- 大纲已定 → 按本节把每章扩成讲义
- 讲义初稿"像论文" → 用第 3 节 12 条逐条转换
- 录课时总卡壳 → 不是你口才差，是讲义没口语化

## 2. 讲义与文章的区别

| 文章 | 讲义 |
|---|---|
| 给"读者"看 | 给"一个人"听 |
| 长句、逻辑严密 | 短句、随时停顿 |
| "综上所述" | "所以你看" |
| 案例放附录 | 案例穿插在讲解里 |
| 怕啰嗦 | 怕听不懂，宁可啰嗦 |

记住：**讲义是"说"的底稿，不是"读"的课文**。照着念都拗口的讲义，录出来就是灾难。

## 3. 口语化转换 12 条

1. **短句**：一句超 40 字 → 拆。讲课不是朗诵
2. **第二人称**：多用"你"，少用"学员们"。课程是讲给"一个人"听的
3. **禁用书面语**："进行/予以/综上所述/鉴于/贯彻落实" → 换成"做/给/所以/因为"
4. **数字说人话**："37.5%" → "将近四成"；"12,800" → "一万二千八"
5. **先给结论**："那个我上次说的…" → 先说结论，背景后补
6. **口头禅清零**：稿子里不许出现"那个/然后/其实"（口头禅是录课时自然带的，稿子里不许有）
7. **每 5 分钟一个"钩子词"**："关键是/但问题来了/最狠的是"——防止学员走神
8. **案例前置**：先讲故事，再讲道理。"比如我有个学员…"比"我们要明白…"管用 10 倍
9. **时态现在时**："你将会学到" → "你现在就能用"
10. **留白标记**：在讲义里标 `[停顿]` `[提问]`，提醒自己别一口气讲完
11. **过渡句口语化**："下面我们进入下一节" → "好，讲完这个，咱们看下一个"
12. **结尾行动化**：每节结尾不是"总结"，是"你现在去做 X"

### 转换三例

- ❌"本节将对选题方法进行系统讲解" → ✅"这节课，我教你 3 步定选题"（短句+你+具体）
- ❌"综上所述，选题是短视频制作的首要环节" → ✅"所以你看，选题定错了，后面全白干"（口语+后果）
- ❌"学员们应当重视数据复盘" → ✅"你今晚就去看一条数据：完播率"（你+行动）

## 4. 讲义结构模板（一节 20–30 分钟）

```
钩子：这节解决你哪个痛点 + 学完你能做到什么
方法步骤，每步配 1 个案例/例子
[提问] 你现在想想，你的 XX 是什么？
你现在去做 X，做完截图发群里
```

铁律：**每节必须有一个"今晚就能做"的行动**，没有行动的节 = 水时长。

## 5. 案例插入三位置

1. **开头**：用案例当钩子（"我有个学员，7 天涨粉 1000"）
2. **方法后**：用案例证明方法有效（"他就是按这三步做的"）
3. **结尾**：用案例推行动（"你也可以，今晚就做"）

案例贵在"像我"：学员要觉得"他行我也行"，不要用大 V 案例打击人。

## 6. 反模式

- ❌ 讲义直接拿公众号文章改——文章是看的，讲义是说的
- ❌ 一节讲 3 个方法——学员一个记不住，一节一个方法
- ❌ 全程无提问无停顿——学员当成背景音，完课率崩
- ❌ 结尾"今天就讲到这里"——换成"你现在去做 X"
- ❌ 案例全是"我朋友"——编的案例一听就假，用自己的或学员的

## 7. 常见问题 FAQ

**Q：讲义要写逐字稿吗？**
A：新手写逐字稿（防忘词），老手写提纲+关键句。逐字稿的好处是口语化可控，坏处是容易"念稿感"——解决办法：写完读三遍，熟到能脱稿。

**Q：口语化会不会显得不专业？**
A：不会。专业体现在"把复杂讲简单"，不体现在"用词多书面"。学员为"听懂"付费，不为"敬畏"付费。

**Q：一节多长合适？**
A：录播 20–30 分钟一节。超过 40 分钟，拆。学员的注意力是按"节"续费的。

**Q：方言/口头禅能保留吗？**
A：适度的个人特色是记忆点，但"然后/那个"成堆就是灾难。录完自己听一遍，数口头禅。

**Q：讲义里要放 PPT 备注吗？**
A：要。`[切 PPT 第 3 页]` `[停顿 3 秒]` 这类标记写进讲义，录课时不手忙脚乱。

## 8. 自检与反馈

每次执行完本 skill，做一次轻量自检：

1. 全稿读出声了吗？→ 没读等于没检测
2. 书面语清零了吗？→ 跑 `course_audit.py` 看 LEC-TONE-001
3. 每节有行动项吗？→ "好好复习"不算
4. "你"出现了吗？→ 通篇"学员们"就是写错了对象

标准冒烟用例：给定一章大纲（四段式），输出一节讲义（含开场/讲解/互动/行动），跑 `course_audit.py` 检查 LEC-TONE-001/LEC-LONG-001 是否通过。

反馈渠道：以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-course-create/issues，正文写清"输入 → 错误输出 → 期望输出"。

## 9. 讲义逐字稿示例（一节 20 分钟）

```markdown
# 第1章第1节：三步选题法

【开场】
你是不是也这样：想拍短视频，第一个问题就把你卡住了——
拍什么？今晚这节课，我教你 3 步定选题，听完你就能定出 3 个。

【讲解】
第一步，找痛点。你回想一下，你的观众最近在为什么烦？
比如做美食的，观众烦的是"不知道今晚吃啥"。
[停顿]

第二步，定人群。痛点有了，是谁的痛点？
学生党和上班族，痛点不一样，选题也不一样。
比如同样是"快手菜"，给学生党讲"5 块钱"，给上班族讲"15 分钟"。
[提问] 你现在想想，你的人群是谁？

第三步，验需求。选题定了，先别拍，去搜一下。
有人搜、有人问，这个选题才有流量。
比如你搜"5 块钱快手菜"，播放量高的，就说明需求在。

【行动】
你现在就做一件事：写下 3 个备选选题。
写完发群里，我明天统一点评。
记住：先完成，再完美。
```

检查：短句✅ "你"高频✅ 案例穿插✅ [停顿][提问]标记✅
结尾是行动不是总结✅。
