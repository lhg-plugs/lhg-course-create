# /lhg-course-create:course-quiz —— 配套习题

用户输入在 `$ARGUMENTS` 中：`[章节讲义或大纲]`（给哪章出哪章的题）。

全程加载 `lhg-cc-quiz` 指导，可分派给 `quiz-checker` agent。

## 流程

### 1. 定范围
- 明确是哪一章、大纲对应知识点是什么。超纲的题不许出。

### 2. 出题
- ≥3 道，记忆/理解/应用三档全覆盖，标注题型+难度。
- 题干具体，一题一测。

### 3. 写答案解析
- 记忆档一句话答案，理解档答案+原理，应用档评分要点。
- **没答案的题不许交付**。

### 4. 一致性检查
- 每题能对应回大纲知识点吗？→ 对应不上的删。
- 跑 `course_audit.py` 看 QUIZ-GRAD-001/QUIZ-ANS-001 是否通过。

## 硬规则
- 三档缺应用档 → warning，必须补。
- 有题没答案 → blocker，不许交付。
- 考了没讲的 → 删题，不许超纲。
